# `.caro.lock` schema reference (schema_version = 2)

The lock is a TOML file generated by Caro and committed to the project. It
holds per-platform variants, A/B candidates, validation outcomes, and the
generation lineage.

## Top-level

```toml
schema_version = 2

[meta]                                  # who wrote this lock
caro_version       = "1.4.0"
intent_path        = "tasks/cleanup-logs.caro"
intent_hash        = "sha256:..."       # over the normalized AST
supported_platforms = ["macos", "linux"]
last_full_regen    = "2026-04-26T12:00:00Z"

[task]                                  # snapshot of the .caro semantics
title  = "Clean up old log files"
why    = "Free disk space"
needs  = ["sudo"]
prefers_by_platform = { macos = ["bsd-tools"], linux = ["gnu-tools"] }
avoids_by_platform  = {}
params = { path = "/var/log", days = "30" }

[[steps]]                               # one per DO line in the .caro
line        = 12
intent      = "find log files in /var/log"
intent_hash = "sha256:..."
notes       = ["prefer single-pass find"]

  [[steps.variants]]                    # 1+ per platform
  platform        = "macos"
  active          = true                # exactly one active per platform
  generation_id   = "gen_2026-04-26_macos_a"
  command         = "files=$(find /var/log -type f -name '*.log')"
  reasoning       = "..."
  exports         = ["files"]
  imports         = []
  risk_level      = "safe"
  matched_patterns = []
  warnings        = []
  confidence      = 0.94
  iterations      = 1
  validations     = [
    { angle = "safety",       result = "pass" },
    { angle = "platform",     result = "pass" },
    { angle = "secrets",      result = "pass" },
    { angle = "side_effects", result = "pass" },
  ]
  generated_at  = "2026-04-26T12:00:00Z"
  model         = "smollm-1.7b"
  backend       = "embedded"
  tool_versions = { find = "BSD-stock-macos14" }
  track_record  = { runs = 42, succeeded = 42, failed = 0,
                    last_used = "2026-04-25T08:30Z" }
  retired_at    = ""                    # set when no longer chosen
  runbook_hash  = "sha256:..."          # body-hash stamped at last `caro export`

[[history]]                             # append-only lineage
generation_id = "gen_2026-04-26_macos_a"
trigger       = "intent_hash_mismatch"
caro_version  = "1.4.0"
model         = "smollm-1.7b"
backend       = "embedded"
platform      = "macos"
generated_at  = "2026-04-26T12:00:00Z"
intent_hash   = "sha256:..."
cve_feed_rev  = "2026-04-26"
notes         = "Initial generation."
```

## Stamps that drive `caro run`

| Field | Where | Compared against | Action on mismatch |
|---|---|---|---|
| `meta.intent_hash` | top-level | `intent_hash(parsed_task)` at run time | HardRegen |
| `steps[i].intent_hash` | per step | hash of step intent | per-step HardRegen |
| `steps[i].variants[j].runbook_hash` | per active variant | body-hash of `tasks/<name>.<plat>.sh` | drift warning + step-by-step fallback |
| `meta.caro_version` | top-level | current Caro version | SoftExplore on `--explore` |
| `variants[j].model` / `variants[j].backend` | per variant | current backend identity | SoftExplore on `--explore` |

## Notes

- The lock's `notes` field on each step mirrors the source `NOTE` lines.
- `track_record` is aggregated from the per-user run journal at
  `~/.caro/state/<intent_hash>/journal.jsonl`. The lock holds the
  team-shared aggregate; the journal holds the per-user signal.
- Retired variants stay in the lock for reference. `caro lock compact`
  (v0.2) prunes them.
